### About

- Working on browser automation, build/CI infrastructure, and design-token tooling.
- Interested in the Rust-for-JS-tooling frontier: NAPI-RS bindings, embedded JS engines, protocol clients.
- I like taking something that only exists as a Node package and finding out what it looks like as a native binary.
